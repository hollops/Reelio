# Sign-in backdrop images

Eleven photographs used as the drifting cover-art wall behind the sign-in and
register forms (`src/features/auth/AuthBackdrop.tsx`).

**Source:** Lorem Picsum (https://picsum.photos), which republishes photographs
from Unsplash for use in designs and mockups.
**Licence:** Unsplash Licence — free to use, including commercially, with no
permission or attribution required. This file is kept as a record of where the
files came from, not because attribution is owed.

Filenames are the Picsum photo IDs, so any image can be traced back to its
original at `https://picsum.photos/id/<name>/info`.

They are decorative only: the wall is `aria-hidden`, so these images carry empty
alt text and are never announced by a screen reader.
